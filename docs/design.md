# Reaper Roulette v0.1.0

Implement the user's supplied specification directly in this plugin root. This is a native RS3 Lua suggestion tool for any logged-in player, with no checks for Reaper tasks, War's Blessing, combat level, or Reaper's Choice. The client, not this plugin, handles accepting tasks.

Use the supplied `mz/roulette_example.png` as a visual reference: dark horizontal ribbon, equal tiles, fixed gold center outline, adjacent tiles visible, and a full winner label below. Use native Canvas/Text/Button components, not HTML or an external overlay. Configuration belongs only in the native Settings gear. Paginated rows keep every boss accessible in small panels; each row has a separate On/Off control and integer weight stepper, with live odds.

The requested native architecture is the appropriate approach. A browser overlay would not meet the native Settings requirement; a built-in carousel would tie selection to UI navigation. Instead a pure weighted draw chooses once, then a deterministic cubic ease-out reel lands on that choice in two seconds. The animation never invokes the RNG.

Store schema-versioned tables with PersistentDB:Get/Set under a key containing the valid self entity's exact displayName. This follows the documented character-name option for per-character storage and avoids the client's failing Tracking permission toggle. Request no permissions, never substitute a shared/default key, and wait/retry while identity is absent. Profiles follow names: renaming starts a new profile and name reuse reuses it. Leave previous Tracking-based saves untouched. Persist changes before accepting them in memory; surface errors without pretending they saved. Defaults for newly introduced roster entries are On/1x. Preserve unknown saved entries for future roster updates.

Use Event.ContentLayerReady and Event.SettingsLayerReady. Use Event.Draw.timeDeltaSecs for animation. Watch visibleGlobal and identity before every frame and action, and use GameStateChanged to clear results at transitions. Unsubscribe the frame callback and invalidate its generation on cancellation; retain a lightweight Logic watcher for login and visibility changes. Replacing/closing the content view, switching character, or changing pool membership clears the spin. Weight-only edits retain the original draw.

Roster: 57 choices, retaining the initial 48 Soul Reaper entries and adding 9 broader combat encounters, including the user's Abomination and Char requests. ED1–3 and Sanctum of Rebirth have only their final bosses; intermediate bosses and WildyWyrm are excluded. IDs remain stable. Legiones, Dagannoth Kings and the original three Rex Matriarchs stay grouped; Osseous is separate and the Matriarchs label states its scope. Nex and Angel of Death are distinct, and normal/hard modes are not duplicated. Additional choices need not be eligible Reaper assignments. Source links and verification notes are recorded in docs/api-notes.md.

Local verification uses real domain modules and a strict test double only at the unavailable RuneScape host boundary. Native rendering, beta permissions and disk persistence require a client smoke test. No Git repository exists here; create files in place and deliver a ZIP without initializing or committing a repository.
